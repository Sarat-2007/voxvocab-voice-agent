# VoxVocab — AI Voice Vocabulary Tutor

Interactive AI Voice Agent designed to assist learners and higher-education aspirants in building workplace vocabulary, pronunciation, and contextual sentence usage.

Built as an operational working prototype for the **Apna Advantage Product Operations Challenge**.

## Live Working Demo
- **URL**: https://sarat-2007.github.io/voxvocab-voice-agent/

## Key Technical & Product Capabilities
1. **Real-Time Speech Recognition (STT)**: Uses Web Speech Recognition API to capture live microphone audio.
2. **Contextual Evaluation**: Validates whether the user correctly pronounced the word or formulated an accurate sentence using the vocabulary word in context.
3. **Voice Audio Synthesis (TTS)**: Uses Web SpeechSynthesis API to deliver spoken feedback, phonetic guidance, and prompts.
4. **Scalable Architecture**: Modular JSON word decks ready to integrate into Apna Advantage counselling and upskilling tracks.
